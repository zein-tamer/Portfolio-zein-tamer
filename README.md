# Zein Tamer - Professional Portfolio

A modern, high-performance personal portfolio showcasing my web and mobile application projects. Built with a focus on clean design, luxury dark-mode aesthetics, and responsive user interfaces.

## 🛠️ Built With
* **React.js** - Frontend Framework
* **React Router** - Navigation & Routing
* **Bootstrap** - UI Component Library & Grid System
* **Custom CSS** - Tailored variables for a premium dark theme

## ⚙️ Features
* **Custom Theme Toggling:** Seamless switching between premium dark and light modes.
* **Responsive Design:** Optimized for all devices (Mobile, Tablet, Desktop).
* **Project Showcase:** Detailed cards featuring high-resolution images and unified aspect ratios.

## 💻 Getting Started
To run this project locally:
1. Clone the repository: `git clone https://github.com/zein-tamer/Portfolio-zein-tamer.git`
2. Install dependencies: `npm install`
3. Start the server: `npm start`
